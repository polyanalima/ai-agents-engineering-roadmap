# Prompt Engineering

O System Prompt define o comportamento do agente.

## Framework de 7 passos

1. Papel: define identidade do agente
2. Diretrizes: tom e estilo
3. Contexto: informações do negócio
4. Restrições: limites claros
5. Passos: lógica de execução
6. Esclarecimento: trata ambiguidades
7. Formatação: estrutura da resposta

## Exemplo aplicado
Agente de suporte técnico com respostas em JSON ou Markdown.

## Prompting reativo
Ajuste contínuo do prompt baseado em erros observados em produção.
