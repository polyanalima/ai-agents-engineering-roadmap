# Engenharia de Produção de Agentes

## Guardrails
Regras que evitam comportamento inesperado da IA.

## Custos
- Modelos maiores = mais caros
- Mais chamadas = maior custo

## Performance
- Latência importa
- Workflows são mais rápidos que agentes

## Confiabilidade
- Workflows: previsíveis
- Agentes: flexíveis, mas menos previsíveis

## Falhas de API
- 400: erro do usuário/configuração
- 500: erro do servidor

## Observabilidade
Monitoramento de execução e logs é essencial em produção
