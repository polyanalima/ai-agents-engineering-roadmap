# APIs e Integrações

Agentes precisam interagir com sistemas externos.

## HTTP
- GET: leitura de dados
- POST: envio de dados

## JSON
Formato padrão de troca de informações.

Exemplo:
{
  "nome": "João",
  "idade": 30
}

## MCP
Protocolo para conectar contexto entre sistemas.

## Importante
Arquivos binários (PDF, imagem) precisam ser convertidos antes de processamento.
