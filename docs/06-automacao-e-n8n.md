# Automação com n8n

n8n é uma ferramenta de automação visual.

## Componentes principais

- Chat Trigger: entrada do usuário
- AI Agent Node: cérebro do fluxo
- Tools: integração com APIs

## Conceito importante
- Workflow: linear e previsível
- Agente: autônomo e dinâmico

## Memória
Window Buffer Memory mantém contexto da conversa.

## Uso ideal
- Workflows: tarefas repetitivas
- Agentes: decisões complexas
