# LLMs e Memória

LLMs (Large Language Models) são o "cérebro" dos agentes.

## Como funcionam
- Recebem input em texto
- Processam contexto
- Geram output em texto

## Limitações
- Não executam ações sozinhos
- Não possuem memória persistente nativa

## Tipos de memória

### Curto prazo
- Janela de contexto da conversa

### Longo prazo
- Bancos vetoriais (ex: Pinecone, Supabase)

## Importante
Sem memória, o agente trata cada mensagem como isolada.
